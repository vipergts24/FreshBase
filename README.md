# FreshBase MVP

FreshBase is a local-first, semantic code collaboration platform managed by AI agents.

## Core Commands
- `fresh init`: Initializes the `.fresh/` metastore locally.
- `fresh index`: Computes vector embeddings of your codebase for the agent Knowledge Engine.
- `fresh revert <intent>`: Semantically reverts an intent and resolves side effects automatically.

See `docs/` for architectural deep-dives.
